# ABOS Control Plane

The `.abos/` directory stores the project-management and engineering-control artifacts for ABOS.

It is deliberately separate from application runtime code.

## Structure

- `tasks/` — task packets and execution status
- `decisions/` — architecture decision records
- `evidence/` — verification evidence and deployment notes
- `architecture/` — system boundaries and design references
- `checklists/` — reusable quality gates
- `prompts/` — portable prompts for engineering agents
- `agents/` — role definitions and operating boundaries
