# Task Packets

Every non-trivial engineering change gets one task packet.

## Naming

`ABOS-<AREA>-<NUMBER>.md`

Examples:

- `ABOS-OPS-001.md`
- `ABOS-AI-014.md`
- `ABOS-SEC-003.md`

## Minimum task sections

- Goal
- Current state / evidence
- Scope
- Non-goals
- Requirements
- Acceptance criteria
- Validation commands
- Rollback plan
- Status
